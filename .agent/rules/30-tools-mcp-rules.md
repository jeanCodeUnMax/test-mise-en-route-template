# TOOLS / MCP / EXTERNAL ACTION RULES

When a task uses a tool, MCP server, connector, external command, or API, record:

- tool name
- purpose
- important input/reference
- important output/reference
- execution result
- evidence path when relevant

Do not claim a tool was used unless it was actually invoked.

If a required tool is unavailable:
- mark the task BLOCKED if the tool is mandatory
- do not fabricate its result
- record the blockage and possible alternatives

Tool use must remain subordinate to TASK_ACTIVE.
Do not browse, code, call MCP, or modify unrelated systems merely because they may be interesting.

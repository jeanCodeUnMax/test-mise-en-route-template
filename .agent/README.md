# HEPHAISTOS `.agent` WORKSPACE PACK

This pack defines workspace rules and reusable skills for:
- brainstorming
- PRD creation
- task/subtask decomposition
- HEPHAISTOS CLI usage
- scientific protocol
- implementation
- evidence / ledger
- MCP/tool traceability
- anti-drift / anti-amnesia
- review and closure

## Core principle
The LLM proposes, reasons, implements, and analyzes.
The deterministic project engine decides state transitions and DONE.

## Suggested usage order
For a new project:
1. `brainstorm`
2. `prd`
3. `task-decomposition`
4. `cli-operation`
5. `implementation` and/or `scientific-experiment`
6. `evidence-and-ledger`
7. `review-and-close`

Use `context-recovery` after interruptions or long sessions.

## Important
Adapt file names/syntax to the `.agent` convention supported by your specific IDE/agent runtime.
The content is intentionally tool-agnostic.

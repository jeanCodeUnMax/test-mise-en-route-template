# SKILL — REVIEW & CLOSE

## Goal
Prevent premature completion and forgotten work.

## Review before DONE
Check:
- objective achieved
- dependencies satisfied
- required outputs present
- tests passed
- evidence present
- docs synchronized
- unresolved errors recorded
- unexpected findings captured
- follow-up/backlog recorded
- Git state coherent

## Scientific close
Also check:
- hypothesis answered
- counter-hypothesis considered
- raw results preserved
- conclusion written
- KEEP / MODIFY / KILL / INCONCLUSIVE selected

## Development close
Also check:
- code works
- tests pass
- interface/docs updated if needed
- no unrelated changes accidentally included

## Final rule
If any mandatory condition fails, task remains ACTIVE or VALIDATING.

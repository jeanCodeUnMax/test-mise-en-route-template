# HEPHAISTOS RADAR

State-of-art reports live here.

Before a promising brainstorm becomes a PRD, create a report named:

```text
state-of-art-YYYYMMDD-short-topic.md
```

Use `STATE_OF_ART_TEMPLATE.md` as the quality bar.

A valid report must answer:

- what exact research/business question is being tested;
- what methods, variants, and baselines are compared;
- which scientific/legal/market sources matter;
- which axes, metrics, benchmarks, and datasets will decide the claim;
- what scaling or crossover curve would make the idea serious;
- what already exists and what useful indices can be reused;
- what significant difference is required;
- what would kill the idea;
- GO / NO_GO / MODIFY / INCONCLUSIVE;
- next action.

The report is not a blog summary. It is a decision gate for PRD authorization.
